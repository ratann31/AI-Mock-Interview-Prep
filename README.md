🚀 AI Mock Interview Platform

An AI-powered Mock Interview Platform built with Next.js, TypeScript, and Firebase that helps users practice technical interviews through simulated interview sessions, structured questions, and real-time interaction.

This project is designed to improve interview preparation by providing a realistic mock interview experience with a clean UI, modern architecture, and scalable backend integration.

🧠 Why This Project?

Preparing for interviews can be stressful and unstructured. This platform solves that problem by:

Simulating real interview scenarios

Allowing repeated practice

Providing structured interview flows

Making interview prep accessible anytime, anywhere

✨ Features

🔐 Authentication

Secure user login & signup using Firebase Authentication

🧑‍💼 Mock Interview Sessions

Start and manage interview sessions

Well-organized interview questions and components

Clean and responsive interface
